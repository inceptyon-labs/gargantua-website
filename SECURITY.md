# Security Policy

This repository is the marketing website for Gargantua. It ships no user data
handling or authentication, but we still take reports seriously.

## Reporting a Vulnerability

Email **jnew00@gmail.com** with details and reproduction steps. Please do not
open a public issue for security-sensitive reports.

You can expect an initial response within a few days. Confirmed issues will be
fixed and disclosed once a patch is live.

For vulnerabilities in the **Gargantua macOS app itself** (not this website),
report through the app's own repository.
